# Week 3: Advanced Data Analysis and Visualization in Logistics

## Overview
This project demonstrates EDA using a **hypothetical dataset** of 120 simulated shipments. It is an educational example, not actual DataCo or company performance.

## Files
- `Task_3_Logistics_EDA_Report.docx` — report with statistics, embedded charts, interpretations, findings, and recommendations.
- `logistics_eda.py` — script to generate the data, statistics, and charts.
- `logistics_hypothetical_dataset.csv` — generated sample data.
- `eda_summary.txt` — summary metrics and mode comparison.
- `visualizations/` — five PNG charts.

## Tools
Python, Pandas, NumPy, Matplotlib.

## Run
Install dependencies:
```bash
pip install pandas numpy matplotlib
```
Run from this folder:
```bash
python logistics_eda.py
```

## Visualizations
1. Delivery-time histogram — distribution and spread.
2. Average transportation cost by mode — category comparison.
3. Distance versus cost scatter plot — association, separated by mode.
4. Correlation heatmap — Pearson correlations between numeric variables.
5. Delivery-time box plot by mode — median and variability.
