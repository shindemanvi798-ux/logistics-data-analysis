

Week 4: Predictive Modeling and Optimization in Logistics
Objective
Forecast delivery time using a hypothetical logistics dataset, compare regression models, evaluate performance, and propose optimization strategies.

Files
Task_4_Predictive_Modeling_Optimization_Report.docx — full report with model selection, metrics, charts, and recommendations.
logistics_predictive_model.py — runnable training and evaluation script.
logistics_predictive_dataset.csv — 500-row simulated dataset.
model_evaluation_results.csv — example evaluation results from the prepared run.
visualizations/ — charts used in the report.
Run
Bash


pip install pandas numpy matplotlib scikit-learn
python logistics_predictive_model.py
Important: The dataset is simulated and the scores are educational examples, not results from actual DataCo/company shipments. The script regenerates evaluation results when run.
